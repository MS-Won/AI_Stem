# 2026-11-26 MVP 화면 시안 v1

- 시안(대표 확인용, 비공개): https://claude.ai/artifact/JSDiEDMHQc1eeU4vYzCJ7y — 랜딩 / 업로드·처리 중 / 결과
- 참고 톤: 대표가 지정한 Allfeat(land-book) — 사이트 CSS에서 추출한 색·글꼴만 참고, 레이아웃·이미지는 따라 하지 않음.

## 브랜드 기초
| 토큰 | 값 | 쓰임 |
|---|---|---|
| 바탕 | `#151515` | 전체 배경 |
| 면 | `#1D1D1B` | 카드·플레이어 |
| 선 | `#383835` | 테두리·구분선 |
| 글자 | `#FFFBEB` | 본문·제목 (크림) |
| 보조 글자 | `#B8B8B8` / `#A6A6A6` | 설명 |
| 강조 | `#FF4A5F` | 주 버튼, 합창 구간, 복구된 파형 (버튼 위 글자는 `#151515`) |
| 일반 분리 파형 | `#6B6B66` / `#8C8C86` | A/B의 '일반 분리' 쪽 |

- 글꼴: TASA Orbiter(라틴, Google Fonts) + 한글은 시스템 고딕(Apple SD Gothic Neo / Malgun Gothic), 숫자·라벨은 JetBrains Mono.
- 로고: 글자 로고 "MS Audio" + 막대 4개 파형 마크(가운데 하나만 강조색). 가칭이라 여기까지만.
- 핵심 장치: 합창 구간을 강조색 띠로 표시하고, A/B 토글에서 '일반 분리'는 그 구간 파형이 꺼지고 '복구'는 채워진다.
